## Extractions

**memory**, *AGENTS.md*: "Reading AGENTS.md directly requires Claude Code v2.1.277 or later. In some
sessions Claude can't read AGENTS.md, so import it from a CLAUDE.md there instead." And: "By
default, Claude reads AGENTS.md only when you have no CLAUDE.md in your working directory or above
it."

**memory**, *Import additional files*: "An import in a project-level memory file is external when
its path resolves outside your working directory, like the home directory import above. The first
time Claude Code encounters external imports in a project, it shows an approval dialog listing the
files. If you decline, the imports stay disabled and the dialog doesn't appear again." And, of
symlinked rules: "Claude Code asks for that approval once per project, in a dialog at the start of
an interactive session."

**settings-reference**, *idleCompaction*: idle compaction runs when, among other conditions,
"Auto-compaction: autoCompactEnabled is on", "Prompt cache: the conversation is on the one-hour
prompt cache TTL", "Size: the conversation's context has reached the token threshold, which you can
change from its default of 200,000", and "Idle time: about 54 minutes have passed since the last
request, and your computer is awake at that point."

**hooks**, *PostCompact*: "In addition to the common input fields, PostCompact hooks receive trigger
and compact_summary. The compact_summary field contains the conversation summary generated by the
compact operation." And, of hook output: "A hook's additionalContext, systemMessage, and
initialUserMessage strings, and its plain stdout, are capped at 10,000 characters".

**headless**, *bare mode*: "--bare is the recommended mode for scripted and SDK calls, and will
become the default for -p in a future release." And: "Set ANTHROPIC_API_KEY before running it,
because bare mode doesn't use your subscription login". And: "In bare mode, Claude Code never reads
OAuth credentials or the system keychain."

**context-window**, *What survives compaction*: "When a long session compacts, Claude Code
summarizes the conversation history to fit the context window." The table on that page says the
project-root CLAUDE.md and unscoped rules are re-injected from disk after compaction.

**changelog**, 2.1.299 (October 14, 2026): "Added idle compaction in the terminal: a 200K+ token
conversation left idle for about 54 minutes is compacted before its one-hour prompt cache expires,
so your next message doesn't reprocess it all". 2.1.277 (September 18, 2026): "Added AGENTS.md
support: in a project with no CLAUDE.md, Claude Code reads AGENTS.md instead; change it under
'Project instructions' in /config".

**best-practices**, *Brainstorm with Claude first*: the example prompt "Interview me until you could
write the spec, then write it to SPEC.md."

**sub-agents**: "Explore and Plan start without your CLAUDE.md files and the git status snapshot to
keep research fast and inexpensive. Other built-in and custom subagents load both, unless you set
omitClaudeMd in a custom subagent's definition to start it without the user, project, and local
CLAUDE.md files."
