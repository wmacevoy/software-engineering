# Contributing

How to work on this repository — for a new teammate and for an agent, who both arrive knowing
nothing
([SE1/A3](https://github.com/wmacevoy/software-engineering/blob/v1.1/guide/10-agents.md#a3)). Keep
it short and true: a change that makes a line here untrue updates it in the same change
([SE1/W11](https://github.com/wmacevoy/software-engineering/blob/v1.1/guide/08-work.md#w11)).

## Run it

- **Prerequisites:** _tools and versions, and how to get them_
- **Build:** `_command_`
- **Run:** `_command_` — _what you should see_
- **Reset to a known state:** `_command_` — _what it wipes, and about how long it takes_
  ([SE1/T5](https://github.com/wmacevoy/software-engineering/blob/v1.1/guide/06-testing.md#t5))

## Check it

- **The full check:** `_command_` — the same one CI runs
  ([SE1/O3](https://github.com/wmacevoy/software-engineering/blob/v1.1/guide/07-operating.md#o3))
- **Success prints:** `_the line that means it passed_`
- **Instruments:** _sanitizers, coverage, linters it runs, and how to see each one fire_
  ([SE1/T3](https://github.com/wmacevoy/software-engineering/blob/v1.1/guide/06-testing.md#t3))

## Rules for this repository

Constraints the code cannot show: _for example, no code from GPL sources; `gen/` is generated, never
edited; requirements are versioned, never edited in place._

## Where things are

- **Working set:** `docs/` — `REQUIREMENTS_vX`, `DESIGN_vX`, `QUEUE`, `FINDINGS`
  ([SE1/W10](https://github.com/wmacevoy/software-engineering/blob/v1.1/guide/08-work.md#w10))
- **Agents:** read `AGENTS.md` in this repository (copied from the
  [guide](https://github.com/wmacevoy/software-engineering/blob/v1.1/AGENTS.md)) and this file before acting.
